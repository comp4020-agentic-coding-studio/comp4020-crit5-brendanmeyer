# Process overview

## What I built - **Shadow Copy**, a browser puzzle game
The player moves with WASD/arrow keys, and then a shadow replays their movement from about two seconds earlier, and each room has buttons, gates and hazards that are arranged so the player has to use imagination, as well as later avoid their own shadow to reach the exit.

## The moments that mattered

1. **Creating a brief dirrectly into `CLAUDE.md` instead of steering room by room.** The obvious way to build a game with a first-time-player constraint is to give Claude a prompt, react, then prompt for the next steps. Instead, before any code existed, I wrote the whole design into `CLAUDE.md` [3db534a](https://github.com/comp4020-agentic-coding-studio/comp4020-crit5-brendanmeyer/commit/3db534a): the core mechanic, the non-negotiable constraints (such as: no tutorial text anywhere, mechanics taught through level design, a clear fail state and ending), and the intended difficulty progression across all six rooms. I knew it had paid off when the entire game,  six rooms matching the intended progression, a test suite covering the delayed shadow, collisions and buttons/gates, was created by Claude had landed in one session without me having to specify those decisions individually as they came up. [`3db534a...5244346`](https://github.com/comp4020-agentic-coding-studio/comp4020-crit5-brendanmeyer/compare/3db534a...5244346). However, this also meant that Claude only had 1 commit for the majority of the game. Next time I will also add that it should commit when various stages are completed.

2. **A green test suite didn't mean the levels were actually right.** Every room's solvability test was passing, but playing the built game myself turned up two rooms that could be beaten without doing the intended puzzle at all. Level 3's gate opened with no visible delay, and level 4's gate could be walked around entirely via gaps in the level's walls. Claude could design geometry that satisfied its own scripted-input tests while still leaving a path a human would find in seconds, so the tests alone weren't sufficient evidence the rooms were fair. I reported both by playing rather than reading the diff, Claude traced the exact geometry with a fixed-step debug script to find the gap, fixed the room layout, and added the failure case itself as a permanent assertion (a bypass attempt must now fail, the intended dodge must still succeed) so the suite actually covers what it claims to from here on. [`c250460`](https://github.com/comp4020-agentic-coding-studio/comp4020-crit5-brendanmeyer/commit/c250460), [`e114614`](https://github.com/comp4020-agentic-coding-studio/comp4020-crit5-brendanmeyer/commit/e114614)
